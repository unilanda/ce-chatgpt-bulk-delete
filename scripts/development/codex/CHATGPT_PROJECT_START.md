# ChatGPT project start — ce-chatgpt-bulk-delete

For development in this repository, use the machine-global `ai-dev` toolkit.

- New project bootstrap: `ai-dev project init` / `ai-dev project adopt`
- New worktree: `ai-dev worktree create`
- Existing worktree bootstrap/refresh: `ai-dev worktree bootstrap`
- Read-only validation: `ai-dev worktree audit`

ChatGPT should manage substantial work using the global cycle:
Design in ChatGPT → full implementation package in ChatGPT → Codex integrate/run/test/
fix/package → ChatGPT reviews actual source/diff/evidence → bounded realistic smoke →
commit/push only when explicitly approved.

Every authoritative autonomous Codex task generated by ChatGPT must require successful
full-task completion to end with exactly `[CODEX_TASK_COMPLETE]` and must prohibit that marker
for partial/blocked/intermediate/STOP-ASK outcomes.

Reusable downloadable artifacts should follow:
`p_ce-chatgpt-bulk-delete_c_<chat-slug>_[cid_<short-id>_]<artifact-name>.<ext>`.
